2. APP PURPOSE & TARGET AUDIENCE
- Purpose & Value: Readlet is a native macOS study workspace for PDFs, EPUBs, and web articles. It solves the difficulty of reading dense foreign-language papers (two-column PDFs with math formulas and figures) by rendering layout-preserving bilingual translations under each paragraph, providing page-by-page AI Voice Narration (`AI Narration`) that explains text and figures aloud, and linking multi-color excerpts to a MarginNote-style Mind Map and flashcards.
- Target Audience: Researchers, university students, engineers, and self-learners on macOS.

3. SETUP & FEATURE INSTRUCTIONS
- Offline Features (No Setup Required):
  Press Cmd+O (File -> Import PDF or Document…) or Cmd+Shift+O (File -> Import from Web…, e.g. https://jvns.ca/blog/2024/11/26/terminal-rules/). Highlighting text in 8 colors, excerpt cards, Mind Maps, search (Cmd+F), and narration with the macOS system voice work offline without setup.
- AI Features (Bilingual Translation, AI Voice Narration, AI Assistant & Flashcards):
  Readlet is a Bring-Your-Own-Key (BYOK) / local-AI app. For App Review testing, configure Settings (Cmd+,) -> General -> Gateway:
  • Base URL: <REVIEW_GATEWAY_URL>
  • API Key: <REVIEW_API_KEY>
  • Protocol: Anthropic Messages
  • Chat / Translation Model: claude-haiku-5-5
  • Speech (TTS) Engine: Gateway (Model: gemini-3.8-flash-tts, Voice: Zephyr) or macOS System Voice
  Then press Cmd+2 for Bilingual view, click "AI Narration" (Cmd+Shift+L) for page-by-page voice explanation (click collapse for the Desktop Mini-Player), click "AI" (Cmd+J) for Q&A, or open Flashcards (Cmd+Shift+K).

4. EXTERNAL SERVICES & PLATFORMS USED
- Apple Native Frameworks: PDFKit (PDF & vector bilingual rendering), WebKit (web article import), AVFoundation / AVSpeechSynthesizer (audio playback, AAC cache, offline system TTS), Speech (optional hold-to-ask voice input during narration).
- User-Configured AI Endpoints (BYOK): Users connect their own API endpoint (Anthropic, OpenAI-compatible, Gemini TTS, or local models via Ollama / LM Studio on localhost). Before the first AI request, Readlet asks for explicit user consent explaining what content is sent to the configured AI service. No analytics, tracking SDKs, authentication, or payment services are used.
